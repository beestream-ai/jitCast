# t0

[← back to the README](../../README.md)

[t0](https://huggingface.co/theforecastingcompany/t0-gamma) is The Forecasting Company's decoder-only
time-series foundation model ([paper](https://arxiv.org/abs/2609.24559)). jitcast reproduces `predict()`
from the reference [`tfc-t0`](https://github.com/theforecastingcompany/tfc-t0) package (0.6.1) end to end:
quantile forecasts for univariate and multivariate series, with past-only and known-future covariates,
any quantile levels and any horizon.

| | |
|---|---|
| Architecture | decoder-only transformer over 32-step patches: a residual-block patch encoder of `[values ‖ time index ‖ validity]` plus a variate-type embedding (target, past-only covariate, known-future covariate); 24 layers of width 1,024 (8 heads of 128, SwiGLU 2,048, per-head RMSNorm of q and k), every third attending across the variates of a series at each patch, the others across time with xPos rotary embeddings; a final RMSNorm, a residual-block decoder and a monotone quantile head of 21 levels (0.01, 0.05, …, 0.95, 0.99). Each patch predicts the next |
| Checkpoints | `theforecastingcompany/t0-gamma` (256M, the latest), `t0-beta` (256M), `t0-alpha` (102M), loaded as published (`model.safetensors` + `config.json`) |
| Engines | `t0.tornado.TornadoT0Engine` (TornadoVM), `t0.cpu.CpuT0Engine` (FP32 reference) |

## Quick start

```bash
mkdir -p t0-gamma && for f in config.json model.safetensors; do
  curl -L -o t0-gamma/$f https://huggingface.co/theforecastingcompany/t0-gamma/resolve/main/$f
done
```

```java
try (ForecastEngine engine = TornadoT0Engine.load(Path.of("t0-gamma"))) {
    List<Forecast> forecasts = engine.forecast(List.of(
            TimeSeries.univariate(history),                              // NaN = missing
            new TimeSeries(targets, pastCovariates, futureCovariates)),  // [V][T], [Vp][T], [Vf][T+H]
            64);
    float[] median = forecasts.get(0).median(0);                         // values[target][quantile][step]
}
```

The forecasting options are `T0Pipeline.Options`, the reference's `predict()` keywords. The defaults are
the reference's: the 21 trained levels, no adjustments, constant known-future covariates dropped.
`withRecommendedAdjustments()` turns on the four adjustments the reference recommends: leading missing
values trimmed, symmetric averaging, non-negative clipping and integer snapping.

```java
T0Pipeline p = engine.pipeline().withOptions(
        T0Pipeline.Options.defaults(engine.config()).withRecommendedAdjustments().withQuantileLevels(0.1, 0.5, 0.9));
```

## Features

| Feature | Supported |
|---|---|
| Inputs | univariate, several joint targets, past-only and known-future numeric covariates (known-future ones cover the context and the horizon), mixed batches, NaN gaps and late starts, ragged lengths |
| Batches | series attend only to their own rows, so a forecast does not depend on its batch; 64 series and 16,384 tokens (rows × patches) per forward pass by default, a larger series runs alone |
| Horizon | any: up to 1,024 steps in one forward pass, then the reference's autoregressive rollout |
| Quantile levels | any in (0, 1): interpolated between the trained levels, extrapolated beyond them on exponential tails |
| Options | `quantileLevels`, `trimLeadingMissing`, `symmetricAveraging`, `clipNonnegative`, `snapIntegers`, `dropConstantCovariates` |
| Precision | FP32 by default; optional FP16 or TF32 GEMM inputs |

## How it maps onto jitcast

| Reference | jitcast |
|---|---|
| `config.json` | `t0.T0Config` (unknown keys and unsupported settings fail the load) |
| `T0Forecaster` parameters | `t0.T0Weights`: every tensor bound by name and shape |
| `T0Forecaster.forward` | `t0.T0Forward`: `cpu.CpuT0`, `tornado.TornadoT0Forward` |
| `TimeSeries`, `MaskType`, `VariateType` | `t0.T0Batch` |
| `CausalScaler` | `t0.T0Scaler` |
| `t0.levels`, `t0.quantile` | `t0.T0Quantiles` |
| `predict`, `rollout`, `_predict_step` | `t0.T0Pipeline`, `T0Pipeline.Options` |

- **Forward pass.** Each row (a target or covariate) has one token per patch, the forecast region's
  patches withheld. Time layers attend causally for targets and past-only covariates and bidirectionally
  for known-future covariates; group layers attend across a series' rows at the same patch, without
  rotary embeddings, and known-future covariates read only known-future covariates. RMSNorm epsilon is
  1e-8 throughout.
- **Host and device.** Batch assembly, the causal scaler (each step's running mean and deviation for
  targets and past-only covariates, the whole row's for known-future covariates, then `asinh`), the
  rollout and the quantile post-processing run on the host. The patch encoder, the transformer, the
  decoder and the quantile head of the forecast patches run on the device, one plan per (rows, patches,
  output patches). Predictions return to data space with `sinh` and the statistics of each patch's last
  step.
- **Long horizons.** Past 1,024 steps each target is repeated once per quantile level, each copy's
  forecast fed back as observations, and the trajectories reduced to the requested levels by weighted
  empirical quantiles, as the reference does. There is no key-value cache: one pass covers up to 1,024
  steps, and each rollout step slides the window, which moves every position.
- **Kernels.** The type embedding, q/k norm with xPos, time and group attention, the patch gather and
  the quantile head are t0's own ([KERNELS.md](../KERNELS.md#t0)); the GEMMs, RMSNorm and SwiGLU are
  shared.

## Options and tuning

`t0.*` options are in [CONFIGURATION.md](../CONFIGURATION.md#t0). The defaults use cuBLAS FP32 with
CUDA graphs on NVIDIA and simdgroup GEMMs on Metal; `-Dt0.tornado.gemm=cublas-fp16` uses FP16 tensor
cores on NVIDIA.

## Limits

- Categorical covariates are not supported: a series with them fails the call. Encode them as
  numbers first.
- Only float32 checkpoints load; on the device, heads up to 128 wide. Every published checkpoint
  qualifies.
