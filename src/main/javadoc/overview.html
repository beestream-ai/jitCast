jitcast runs zero-shot time-series foundation models in Java, on GPUs through TornadoVM.

Every model is a {@link ai.beestream.jitcast.api.ForecastEngine}. Load one, pass it a batch of {@link ai.beestream.jitcast.api.TimeSeries} and a horizon, and read the quantiles from each {@link ai.beestream.jitcast.api.Forecast}:

{@code
try (ForecastEngine engine = TornadoTimestralEngine.load(Path.of("Timestral-5M"))) {
    List forecasts = engine.forecast(List.of(TimeSeries.univariate(history)), 64);
    float[] median = forecasts.get(0).median(0);        // values[target][quantile][step]
}
}

The TornadoVM engines run on CUDA, OpenCL and Metal; the CPU engines are FP32 references for validation. A pipeline's {@code with…} methods change its settings, such as cross-learning for Chronos-2 or sign-flip averaging for Timestral. Engine options are JVM properties, read when an engine is created; {@link ai.beestream.jitcast.tornado.Devices} reads the device and memory settings. The options are listed in CONFIGURATION.md.
